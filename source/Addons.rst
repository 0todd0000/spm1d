Add-ons
=====================================

This page contains links to third-party add-ons for **spm1d**.

If you require technical support for these add-ons, please contact the add-on author(s) by following the links below.

|
|



.. _label-fctSPM:


(Matlab) Factorial SPM with *post hoc* tests
--------------------------------------------

Compute ANOVA and *post hoc* tests from anova1 to anova3rm, with a non-parametric approach (permutation tests).

`Repostiory @ GitHub <https://github.com/tramarobin/fctSPM>`_

`Code @ Matlab Central <https://www.mathworks.com/matlabcentral/fileexchange/77945-fctspm>`_


|
|


.. _label-guiSPM:


(Python) Graphical user interface for spm1d
--------------------------------------------

Ready-to-use GUI for spm1d, requiring no programming knowledge.

Currently only available in Chinese (as of 2026 Feb.)

`Repostiory @ GitHub <https://github.com/shanshanfagu/SPM1D-Analysis-Wrapper-Program>`_
